# Админ кабинет «Мой тёплый дом»

Сервер и экран админки сайта. Запуск для владельца — [ЗАПУСК.md](ЗАПУСК.md).

Код живёт в ветке `claude/zen-cray-kcbb6t` закрытого репозитория сайта (папка `admin`), данные — в ветке `admin-data`
(сервер создаёт её сам при первом запуске). В основную ветку сайта (`main`) эту папку **не сливать**:
Render открыто публикует всё, что лежит в `main`.

## Как устроено

- **Сайт = сборка(данные).** Каждая страница — это скелет разметки (`skeletons/`) плюс поля с текстами
  (`data/pages/*.json`), общие части из шаблонов (`templates/`) и контакты (`data/site.json`).
  Сборка всех 80 страниц совпадает с сайтом байт в байт: `node build/check.js`.
- **Правка — это список операций** (`server/data.js`): текст, заголовок, фото, контакты, ставки,
  ручная цена, скрыть/показать/скопировать дом. У каждой операции есть обратная — для отката.
- **Публикация** (`server/app.js → publish`): применить операции, пересчитать подборки по цене,
  проверить, собрать сайт, записать данные и сайт в git. Правки мимо админки обнаруживаются и не затираются.
- **Цены** — формулы из `v2/calc-live.js`, ставки из облака калькулятора (`server/calc.js`).
  Ставки меняются в облаке, и калькулятор менеджеров видит их сразу; ссылки КП (`_link_…`) сохраняются.
- **Заявки с сайта** — `POST /lead` (формат `v2/form.js`) → amoCRM (`server/amo.js`) и вебхуки.
- **Вход** — логин и пароль (scrypt), подписанный ключ на 30 дней; роли Владелец и Редактор.

## Папки

| Папка | Что там |
|---|---|
| `build/` | сборка страниц: общие части, SEO, тексты, цены, sitemap, списки домов, разбор страницы |
| `server/` | сервер: ядро, операции, git, вход, калькулятор, amoCRM, заявки, веб |
| `ui/` | экран админки (без библиотек) |
| `data/`, `skeletons/`, `templates/` | данные сайта (в закрытом репозитории — ветка `data`) |
| `tools/` | перенос данных с сайта (`init-*.js`), подготовка ветки данных (`seed.js`) |
| `test/` | тестовый стенд и 21 долгий тест: `node test/run.js` (TEST_MINUTES, PARALLEL, SEED) |

## Проверки

- `node build/check.js` — сайт собирается из данных байт в байт.
- `node test/dev.js` — тестовая админка на http://127.0.0.1:8765 (код первого входа START); настоящий сайт не трогается.
- `TEST_MINUTES=5 node test/run.js` — долгие тесты.

## Замечено на сайте (не исправлено, ждёт решения владельца)

- Кнопка Telegram ведёт на `https://t.me/` без аккаунта; кнопка MAX — на `#max`. Правится в админке: «Контакты».
- 404.html: ссылка «Как нас найти» ведёт на `#contacts`, а такого блока на этой странице нет; логотип ведёт на пустой адрес.
- В меню написано «24 проекта в 5 сериях». При скрытии или копировании дома число само не меняется.
- В движке калькулятора на сайте (`v2/kalk-dom-engine.js`) зашиты старые ставки (34 500 ₽ вместо 37 000 ₽).
  Если облако не ответит, всплывающий калькулятор посчитает по ним.

## Известные ограничения (сознательно не сделано или отложено)

- **Не сделано:** метка «Хит» и закрепление домов наверху каталога, автосортировка каталога. Каталог хранит свой нынешний порядок; скрытые дома возвращаются на своё место.
- **Не сделано:** добавление новых блоков на страницу из админки. Меняются тексты, фото, цены, контакты и SEO; разметку меняет Claude.
- **Цены текстом в статьях** и число домов в текстах подборок не пересчитываются. Админка предупреждает, когда меняется состав подборок.
- **Число «24 проекта» в меню** не меняется само при скрытии или копировании дома (есть предупреждение).
- **Фото в формате HEIC** переводит в JPG сам браузер (Safari). В других браузерах админка просит сохранить фото как JPG.
- **Редкая гонка.** Если Claude закоммитит в тот же файл сайта в ту же секунду, когда идёт публикация из админки, публикация остановится с сообщением. Правка из админки при этом сохранится в данных, но не на сайте. После «Забрать правки» Claude-версия страницы станет основной, и правку админки нужно будет повторить.
- **Защита от повторных заявок** хранится в памяти сервера. После перезапуска повтор той же заявки из браузера клиента может создать вторую сделку. Это возможно, только если ответ сервера потерялся в сети.

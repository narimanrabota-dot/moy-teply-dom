# Правила для Claude в репозитории сайта «Мой тёплый дом»

Сайт управляется админ кабинетом (закрытый репозиторий `narimanrabota-dot/moy-teply-dom-admin`).
Страницы `v2/*.html`, `v2/calc-live.json`, `v2/form.js` и `sitemap.xml` **собирает админка** из своих данных.

## Главное правило

Не правь тексты, цены, фото, контакты и SEO прямо в `v2/*.html`. Это делается в админке.
Если правка всё же нужна в HTML (новый блок, другой дизайн):

1. Подключи закрытый репозиторий админки (ветка `main` — код, ветка `data` — данные сайта).
2. Правь данные и шаблоны там:
   - общие части (шапка, меню, подвал, окно заявки): `templates/*.html` на ветке `data`;
   - разметка страницы: `skeletons/<страница>.html`;
   - тексты: `data/pages/<страница>.json`.
3. Проверь сборку: `node build/check.js` — все страницы должны собраться без ошибок.
4. Опубликуй через админку или закоммить собранные страницы в этот репозиторий.

Если всё-таки поправил HTML напрямую, админка заметит это и не даст публиковать, пока Владелец
не нажмёт «Забрать правки в админку». Правки в шапке, меню и подвале так не забираются — их нужно внести в шаблон.

## Не запускать

Старые скрипты с Mac: `tools/seo.py`, `tools/prices_export.py`, `tools/check_live.py`, `tools/kalk_dom.py --write`.
Их работу теперь делает админка. Скрипты перезаписали бы её данные.

## Цены

Цены домов считаются по формулам `v2/calc-live.js` и ставкам калькулятора (Supabase, общий с калькулятором менеджеров).
Меняет их только Владелец в админке.

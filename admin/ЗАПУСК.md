# Как запустить админ кабинет

Всё, что можно было сделать без доступа к вашим аккаунтам, сделано и проверено.
Осталось 4 шага в ваших GitHub и Render. Это займёт около 15 минут. Если где-то запутаетесь — пришлите скриншот Claude.

## Шаг 1. Закрытое хранилище для админки (GitHub, 1 минута)

1. Откройте https://github.com/new
2. Repository name: `moy-teply-dom-admin`
3. Выберите **Private**. Галочки ниже не ставьте.
4. Нажмите **Create repository**.
5. Напишите Claude: «создал репозиторий». Claude сам положит туда админку и данные сайта.

## Шаг 2. Ключ доступа к GitHub (2 минуты)

Он нужен, чтобы админка могла записывать правки на сайт.

1. Откройте https://github.com/settings/personal-access-tokens/new
2. Token name: `админка сайта`. Expiration: **1 year**. За месяц до конца срока админка напомнит.
3. Repository access → **Only select repositories** → выберите `moy-teply-dom` и `moy-teply-dom-admin`.
4. Permissions → Repository permissions → **Contents: Read and write**.
5. **Generate token** → скопируйте ключ (начинается с `github_pat_`). Он нужен в шаге 3.

## Шаг 3. Сервер админки (Render, 10 минут)

1. Откройте https://dashboard.render.com → **New** → **Web Service**.
2. Выберите репозиторий `moy-teply-dom-admin`, ветка `main`.
3. Name: `moy-teply-dom-admin`. Region: Frankfurt.
4. Build Command: `npm install`. Start Command: `npm start`.
5. Instance Type: **Starter** (около $7 в месяц, не засыпает).
6. Environment → добавьте переменные:

| Переменная | Значение |
|---|---|
| `ADMIN_SECRET` | любая длинная строка из 40+ случайных символов |
| `BOOTSTRAP_CODE` | придумайте код первого входа, например `старт-2026` |
| `DATA_REPO_URL` | `https://КЛЮЧ@github.com/narimanrabota-dot/moy-teply-dom-admin.git` |
| `SITE_REPO_URL` | `https://КЛЮЧ@github.com/narimanrabota-dot/moy-teply-dom.git` |
| `CALC_URL` | `https://lrykfhnohecxdiipweqi.supabase.co` |
| `CALC_KEY` | `sb_publishable_037PqHLp_UOoM1nfAaU2BQ_6RfwybIy` (публичный ключ, он и так есть на сайте) |
| `CALC_PIN` | ваш админский PIN калькулятора |
| `PUBLIC_URL` | `https://moy-teply-dom-admin.onrender.com` (адрес, который покажет Render) |

Вместо `КЛЮЧ` вставьте ключ из шага 2.

7. **Create Web Service**. Через 2–3 минуты сервис запустится.

## Шаг 4. Первый вход

1. Откройте `https://moy-teply-dom-admin.onrender.com`.
2. Введите код первого входа (`BOOTSTRAP_CODE`), своё имя, логин и пароль не короче 10 символов.
3. Вы — Владелец. Редакторов добавляйте в «Пользователи».
4. В «Интеграции и заявки»:
   - подключите amoCRM: адрес, долгосрочный токен, воронка, этап, ответственный;
   - нажмите «Подключить форму к админке». С этого момента заявки с сайта идут в amoCRM.

После этого Claude сольёт ветку с сайтом. На сайте появится адрес `/admin`, он ведёт на сервер админки.

## Что проверено до запуска

- Все 80 страниц сайта собираются из данных админки байт в байт. Внешний вид не меняется.
- 21 долгий тест, каждый не меньше 5 минут. Результаты — в отчёте Claude.

## Если что-то пошло не так

- **Админка не открывается.** Render → сервис → Logs. Пришлите последние строки Claude.
- **Сайт не обновился после публикации.** На главной админки будет красная плашка и кнопка «Повторить».
- **Нужно срочно всё выключить.** Render → сервис → Suspend. Сайт продолжит работать как обычно.
- **Забыли пароль Владельца.** Render → Environment → добавьте `OWNER_RESET` со значением `ваш-логин:новый-пароль` (пароль не короче 10 символов) → Save. Сервер перезапустится, войдите с новым паролем и **удалите** `OWNER_RESET`.

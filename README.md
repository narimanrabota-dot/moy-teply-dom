# Мой тёплый дом

Одностраничный сайт каркасных домов. Внутри — каталог проектов, страница проекта
со слайдером и планировками, десять внутренних экранов («Как строим», «Где живут
наши рабочие», «Материалы», «Кровля», «Ветрозащита» и другие), отзывы и видеообзоры.

Сайт статический: никакой сборки и зависимостей, только HTML, CSS и обычный JavaScript.

## Структура

```
index.html      разметка всех экранов
css/style.css   все стили
js/main.js      вся логика: слайдер, лайтбокс, планировки, переключение экранов, плеер
img/            фотографии, обложки карточек, планировки (webp)
```

## Как запустить локально

Файлы обращаются друг к другу по относительным путям, поэтому открывать
`index.html` двойным щелчком не нужно — поднимите простой сервер в папке сайта:

```bash
python3 -m http.server 8080
```

Дальше откройте http://localhost:8080

Остановить сервер — `Ctrl+C` в том же терминале.

## Как добавить новый объект

Объекты живут в разделе «Сданные объекты» — блок `<div class="obj-grid">` в `index.html`.
Одна карточка — один `<button class="rev">`.

1. Положите фотографии в `img/`. Имена — по смыслу: `obekt-8-01-fasad.webp`,
   `obekt-8-cover.webp`. Формат webp, ширина 1200–1600 px для фото галереи
   и 600–800 px для обложки.
2. Скопируйте соседнюю карточку и поправьте в ней:
   - `data-t` — заголовок в плеере;
   - `data-items` — список того, что откроется по клику (см. ниже);
   - `<img src>` и `alt` внутри `rev__ph` — обложка карточки;
   - `rev__cnt` — подпись «1 видео · 4 фото»;
   - `rev__n` и `rev__d` — название и описание под обложкой.

`data-items` — это JSON в одинарных кавычках. Каждый элемент:

```json
{"t": "v", "s": "https://rutube.ru/play/embed/ИДЕНТИФИКАТОР", "c": "Видеообзор объекта"}
{"t": "i", "s": "img/obekt-8-01-fasad.webp", "c": "Фасад с террасой"}
```

- `t` — `v` для видео, `i` для фотографии;
- `s` — ссылка на встраивание Rutube или путь к файлу в `img/`;
- `c` — подпись, она видна в плеере.

Ссылку Rutube вида `https://rutube.ru/video/ИДЕНТИФИКАТОР/` превращайте в
`https://rutube.ru/play/embed/ИДЕНТИФИКАТОР`. Для приватного ролика добавьте ключ:
`https://rutube.ru/play/embed/ИДЕНТИФИКАТОР/?p=КЛЮЧ`.

Если у объекта только один ролик и никакой галереи, `data-items` не нужен — хватит
`data-embed="https://rutube.ru/play/embed/..."`. Свой файл вместо сервиса задаётся
через `data-src="video/obekt-8.mp4"`; при заполненных обоих побеждает `data-embed`.

## Как добавить отзыв

Отзывы лежат в разделе «Отзывы» — блоки `<div class="revs">`. Карточка устроена
так же, как карточка объекта: тот же `<button class="rev">`, тот же `data-items`
или `data-embed`.

1. Кадр из ролика сохраните как `img/otzyv-klienta-5-cover.webp`.
2. Скопируйте предыдущую карточку отзыва, замените обложку, `data-t`,
   ссылку на видео и подписи `rev__n` / `rev__d`.

Порядок карточек на странице — это порядок кнопок в разметке, отдельного списка нет.

## Мелочи, о которых легко забыть

- У каждой картинки должен быть осмысленный `alt` — его читают поисковики и
  программы для незрячих.
- Первой фотографии на экране оставляйте `fetchpriority="high"`, остальным —
  `decoding="async"`.
- Пути к картинкам пишутся без ведущего слэша: `img/файл.webp`, а не `/img/файл.webp`.

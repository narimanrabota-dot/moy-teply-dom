Карточка `v2/proekt-9h7.html` (17.09.2026): 5 фото в галерее, 14 живых фото, цена из калькулятора (extra_models.json), **три планировки** с описаниями из PDF владельца и 3D у каждой.

**Why:** владелец присылает планировки по одной (чертёж SVG/PNG + PDF с описанием + отдельно 3D) и ждёт, что каждая встанет в карточку целиком.

**How to apply:** чертежи всех планировок этой карточки разворачиваются так, чтобы **терраса была справа** (требование владельца — все планы смотрят в одну сторону). Разворот делается по исходному SVG, а не по картинке: обернуть содержимое в `<g transform="rotate(-90)">`, viewBox `(minY, -(minX+W), H, W)`, подписи комнат и мебели — `transform="rotate(90 x y)"` у своего якоря, вторую строку пары («площадь») сдвинуть в `(x-195, y)`, у боковых размеров `rotate(-90)` → `rotate(90)`; рендер `qlmanage -t -s 2600`, обрезать поля, 1600 px. Готовый развёрнутый SVG класть в `tools/plans/`. Тексты описания — из PDF через PDFKit: `osascript -l JavaScript` + `PDFDocument.string` (poppler и pdftotext на машине нет). См. [[zhivye-foto-razdel]], [[ceny-vsegda-iz-kalkulyatora]].
